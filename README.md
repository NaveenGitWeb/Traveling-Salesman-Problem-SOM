Traveling Salesman Problem Using Self-Organizing Maps (SOM)

Project Overview
This project implements a solution to the Traveling Salesman Problem (TSP) using a Self-Organizing Map (SOM), an unsupervised neural network approach.
The algorithm organizes neurons to approximate an efficient route connecting multiple cities.

Technologies Used
Python
NumPy
Matplotlib
Artificial Neural Networks concepts
Self-Organizing Maps (SOM)

Project Files
SOM_TSP.py – Main Python implementation.
TSP with help of ANN Report.pdf – Project report.

Installation
Install Python, then install the required libraries:
pip install -r requirements.txt

How to Run
Run the following command:
python SOM_TSP.py
1. Enter the requested values:
2. Number of cities
3. Number of neurons
4. Initial learning rate

The program generates random cities, trains the SOM, calculates a tour, and displays a visualization.

Output

The program displays:
1. Generated cities
2. SOM neuron path
3. Calculated TSP tour
